# what is in this directory

Byte copies of the exam dir as the eval left it (generation 2), taken from
`$KX_ROOT/exams/<origin-key>/tally-refund/`. `manifest-gen1.md` is
`git show HEAD~1:manifest.md` from the exam dir, i.e. generation 1 —
the exam dir is its own git repo, so its history is the generation history.
`git-log.txt` is that log. The pointer pair are siblings of the exam dir,
never inside it.

Not copied: exam_harness.py, exam_anchor.py and
requirement_surface.py, which are byte copies of the skill files already in
this repo (verified in logs/harness-tests.log).
